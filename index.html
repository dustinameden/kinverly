# Kinverly Sprint 50 — Auth + Flock Lifecycle Reset ## Goal Rebuild the entire login, onboarding, admin, flock creation, logout, switch-user, and login recovery flow around one clean identity model. This sprint replaces the old profile-picker onboarding logic with a real account/session system. --- ## Core Rule Kinverly identity must always resolve in this order: 1. `user_id` — the Kinverly account/person. 2. `flock_id` — the flock context. 3. `member_id` — the user’s membership row inside that flock. The app should never treat display names, usernames, avatar names, Firestore IDs, or legacy labels like `mom` as relationship keys. --- # Canonical Tables ## users ```sql users - user_id INT PRIMARY KEY - username TEXT UNIQUE NOT NULL - password_hash TEXT NOT NULL - display_name TEXT NOT NULL - avatar TEXT NULL - global_role TEXT NOT NULL DEFAULT 'user' -- user | admin - status TEXT NOT NULL DEFAULT 'active' -- active | disabled | removed - firestore_id TEXT NULL -- legacy/debug only - created_at DATETIME NOT NULL - updated_at DATETIME NOT NULL - deleted_at DATETIME NULL ``` Rules: - `user_id` is numeric. - `username` is for login only. - `global_role = admin` gives access to all flocks. - Admins do not need fake `flock_members` rows. - Legacy string IDs live only in `firestore_id`. --- ## flocks ```sql flocks - flock_id INT PRIMARY KEY - flock_name TEXT NOT NULL - invite_code TEXT UNIQUE NOT NULL - created_by_user_id INT NOT NULL - status TEXT NOT NULL DEFAULT 'active' - firestore_id TEXT NULL - created_at DATETIME NOT NULL - updated_at DATETIME NOT NULL - deleted_at DATETIME NULL ``` Rules: - `created_by_user_id` must be numeric. - Creating a flock always creates a matching `flock_members` row for the creator unless the creator is a global admin creating a flock on behalf of someone else. --- ## flock_members ```sql flock_members - member_id INT PRIMARY KEY - flock_id INT NOT NULL - user_id INT NOT NULL - role TEXT NOT NULL DEFAULT 'member' -- organizer | member - status TEXT NOT NULL DEFAULT 'active' -- active | invited | removed - joined_at DATETIME NOT NULL - created_at DATETIME NOT NULL - updated_at DATETIME NOT NULL - deleted_at DATETIME NULL UNIQUE(flock_id, user_id) ``` Rules: - `member_id` is the membership lane. - `user_id` is the person lane. - `flock_id` is the family/group lane. - Never create duplicate rows for the same `user_id + flock_id`. --- # Numeric ID Generation All primary IDs are numeric. ```js function nextNumericId(rows, idField) { const ids = rows .map(row => Number(row[idField])) .filter(Number.isFinite); return ids.length ? Math.max(...ids) + 1 : 1; } ``` Tie-breaking for migration: ```js function sortForMigration(rows) { return rows.slice().sort((a, b) => { const aDate = new Date(a.created_at || 0).getTime(); const bDate = new Date(b.created_at || 0).getTime(); if (aDate !== bDate) return aDate - bDate; return String(a.firestore_id || a.id || a.username || '') .localeCompare(String(b.firestore_id || b.id || b.username || '')); }); } ``` --- # Session State Session stores only account-level and last context hints. ```js session = { current_user_id: null, last_active_flock_id: null, remember_device: true } ``` Rules: - Session does not store display name as identity. - Session does not store username as identity. - Session does not permanently store `member_id`. - `member_id` is resolved fresh after `user_id + flock_id` are known. --- # App Boot Router ```js async function bootKinverly() { hideAllAuthScreens(); showBootLoader(); const session = readSession(); if (!session?.current_user_id) { clearBootLoader(); showSignInScreen(); return; } const user = await getUserById(Number(session.current_user_id)); if (!user || user.status !== 'active') { clearSessionOnly(); clearBootLoader(); showSignInScreen(); return; } await routeSignedInUser(user, session.last_active_flock_id); } ``` --- # Signed-In Routing ```js async function routeSignedInUser(user, preferredFlockId = null) { setCurrentUser(user); if (user.global_role === 'admin') { const flocks = await getActiveFlocks(); clearBootLoader(); showAdminFlockDirectory({ user, flocks }); return; } const memberships = await getActiveMembershipsByUserId(user.user_id); if (!memberships.length) { clearBootLoader(); showJoinCreateFlockScreen({ user }); return; } const selectedMembership = chooseBestMembership(memberships, preferredFlockId); const flock = await getFlockById(selectedMembership.flock_id); if (!flock || flock.status !== 'active') { const fallbackMembership = memberships.find(m => m.flock_id !== selectedMembership.flock_id); if (fallbackMembership) { const fallbackFlock = await getFlockById(fallbackMembership.flock_id); enterFlock({ user, flock: fallbackFlock, member: fallbackMembership }); return; } clearBootLoader(); showJoinCreateFlockScreen({ user }); return; } enterFlock({ user, flock, member: selectedMembership }); } ``` ```js function chooseBestMembership(memberships, preferredFlockId) { const active = memberships.filter(m => m.status === 'active' && !m.deleted_at); if (preferredFlockId) { const preferred = active.find(m => Number(m.flock_id) === Number(preferredFlockId)); if (preferred) return preferred; } return active.sort((a, b) => { const aDate = new Date(a.joined_at || a.created_at || 0).getTime(); const bDate = new Date(b.joined_at || b.created_at || 0).getTime(); return bDate - aDate; })[0]; } ``` --- # Create Account Flow ## UI First screen: ```text Welcome to Kinverly [Sign In] [Create Account] ``` Create account form: ```text Create your account Display name Username Password Confirm password [Create account] ``` ## Logic ```js async function createAccount({ displayName, username, password }) { const cleanUsername = username.trim().toLowerCase(); if (!displayName.trim()) throw new Error('Display name is required.'); if (!cleanUsername) throw new Error('Username is required.'); if (password.length < 6) throw new Error('Password must be at least 6 characters.'); const existing = await getUserByUsername(cleanUsername); if (existing) throw new Error('That username is already taken.'); const users = await getUsers(); const now = nowIso(); const user = { user_id: nextNumericId(users, 'user_id'), username: cleanUsername, password_hash: await hashPassword(password), display_name: displayName.trim(), avatar: null, global_role: 'user', status: 'active', firestore_id: null, created_at: now, updated_at: now, deleted_at: null }; await saveUser(user); writeSession({ current_user_id: user.user_id, last_active_flock_id: null, remember_device: true }); showJoinCreateFlockScreen({ user }); } ``` --- # Sign In Flow ## UI ```text Sign in to Kinverly Username Password [Sign In] Create account ``` ## Logic ```js async function signIn({ username, password, rememberDevice = true }) { const cleanUsername = username.trim().toLowerCase(); const user = await getUserByUsername(cleanUsername); if (!user || user.status !== 'active') { throw new Error('No active account found for that username.'); } const ok = await verifyPassword(password, user.password_hash); if (!ok) throw new Error('Incorrect password.'); const previousSession = readSession(); writeSession({ current_user_id: user.user_id, last_active_flock_id: previousSession?.last_active_flock_id || null, remember_device: rememberDevice }); await routeSignedInUser(user, previousSession?.last_active_flock_id || null); } ``` --- # Create Flock Flow ## UI Only appears after account creation or sign-in when the user has no flock membership. ```text Start a new flock Flock name [Create flock] ``` ## Logic ```js async function createFlockForCurrentUser({ flockName }) { const user = getCurrentUserOrThrow(); const now = nowIso(); const flocks = await getFlocks(); const members = await getFlockMembers(); const flock = { flock_id: nextNumericId(flocks, 'flock_id'), flock_name: flockName.trim(), invite_code: generateInviteCode(), created_by_user_id: user.user_id, status: 'active', firestore_id: null, created_at: now, updated_at: now, deleted_at: null }; await saveFlock(flock); const membership = { member_id: nextNumericId(members, 'member_id'), flock_id: flock.flock_id, user_id: user.user_id, role: 'organizer', status: 'active', joined_at: now, created_at: now, updated_at: now, deleted_at: null }; await saveFlockMember(membership); writeSession({ current_user_id: user.user_id, last_active_flock_id: flock.flock_id, remember_device: true }); enterFlock({ user, flock, member: membership }); } ``` Critical rule: ```text Create Flock must not route through onboarding after save. It must immediately create the membership row and call enterFlock(). ``` --- # Join Flock Flow ## UI Only appears after sign-in/account creation. ```text Join a flock Invite code [Join flock] ``` ## Logic ```js async function joinFlockWithCode({ inviteCode }) { const user = getCurrentUserOrThrow(); const now = nowIso(); const flock = await getFlockByInviteCode(inviteCode.trim().toUpperCase()); if (!flock || flock.status !== 'active') { throw new Error('No active flock found for that invite code.'); } const existing = await getFlockMemberByUserAndFlock(user.user_id, flock.flock_id); if (existing && existing.status === 'active' && !existing.deleted_at) { writeSession({ current_user_id: user.user_id, last_active_flock_id: flock.flock_id, remember_device: true }); enterFlock({ user, flock, member: existing }); return; } const members = await getFlockMembers(); const membership = { member_id: nextNumericId(members, 'member_id'), flock_id: flock.flock_id, user_id: user.user_id, role: 'member', status: 'active', joined_at: now, created_at: now, updated_at: now, deleted_at: null }; await saveFlockMember(membership); writeSession({ current_user_id: user.user_id, last_active_flock_id: flock.flock_id, remember_device: true }); enterFlock({ user, flock, member: membership }); } ``` --- # Admin Account Flow ## Admin Creation Admin creation is a special setup flow. ```text Create Admin Login Display name Username Password Confirm password Admin setup key [Create admin] ``` ## Logic ```js async function createAdminAccount({ displayName, username, password, setupKey }) { if (!isValidAdminSetupKey(setupKey)) { throw new Error('Invalid admin setup key.'); } const cleanUsername = username.trim().toLowerCase(); const existing = await getUserByUsername(cleanUsername); if (existing) throw new Error('That username is already taken.'); const users = await getUsers(); const now = nowIso(); const admin = { user_id: nextNumericId(users, 'user_id'), username: cleanUsername, password_hash: await hashPassword(password), display_name: displayName.trim(), avatar: null, global_role: 'admin', status: 'active', firestore_id: null, created_at: now, updated_at: now, deleted_at: null }; await saveUser(admin); writeSession({ current_user_id: admin.user_id, last_active_flock_id: null, remember_device: true }); const flocks = await getActiveFlocks(); showAdminFlockDirectory({ user: admin, flocks }); } ``` ## Admin Routing Rule ```text Admin never lands on Join/Create Flock unless they explicitly choose to create a flock. ``` Admin flow: ```text Sign In → user.global_role = admin → Admin Flock Directory → select flock → enter as admin viewer ``` Admin selected flock context: ```js async function adminEnterFlock(flock_id) { const user = getCurrentUserOrThrow(); if (user.global_role !== 'admin') throw new Error('Admin access required.'); const flock = await getFlockById(Number(flock_id)); if (!flock) throw new Error('Flock not found.'); writeSession({ current_user_id: user.user_id, last_active_flock_id: flock.flock_id, remember_device: true }); enterFlock({ user, flock, member: null, adminMode: true }); } ``` --- # Logout Flow Logout must be boring. ```js function logout() { clearSessionOnly(); clearCurrentUserContext(); clearActiveFlockContext(); hideAppShell(); showSignInScreen(); } ``` Logout must not: - delete user - remove membership - clear flock data - create duplicate users - show the old profile picker - show Join/Create before Sign In --- # Switch User Flow Switch user is logout plus sign-in. ```js function switchUser() { clearSessionOnly(); clearCurrentUserContext(); clearActiveFlockContext(); hideAppShell(); showSignInScreen({ mode: 'switch_user' }); } ``` After the new user signs in: ```text Admin → Admin Flock Directory User with memberships → last/first active flock User with no memberships → Join/Create Flock ``` --- # Enter Flock ```js function enterFlock({ user, flock, member, adminMode = false }) { if (!user?.user_id) throw new Error('Missing numeric user_id.'); if (!flock?.flock_id) throw new Error('Missing numeric flock_id.'); if (!adminMode && !member?.member_id) { throw new Error('Normal users must have a numeric member_id to enter a flock.'); } setCurrentUser(user); setActiveFlock(flock); setActiveMember(member || null); setAdminMode(Boolean(adminMode)); hideAllAuthScreens(); showAppShell(); renderHome(); } ``` --- # Remove Old Profile Picker Delete or disable: ```text Who's logging in? Got: ${row[field]}`); } }); } ``` Use before save: ```js assertNumericIdentity(user, ['user_id']); assertNumericIdentity(flock, ['flock_id', 'created_by_user_id']); assertNumericIdentity(member, ['member_id', 'flock_id', 'user_id']); ``` --- # Export Requirements Admin exports must reflect the clean model: ## users export ```text user_id username display_name global_role status created_at updated_at deleted_at firestore_id ``` No `member_id` in users. ## flock_members export ```text member_id flock_id user_id role status joined_at created_at updated_at deleted_at ``` ## flocks export ```text flock_id flock_name invite_code created_by_user_id status created_at updated_at deleted_at firestore_id ``` --- # Definition of Done This sprint is complete only when: - Logging out shows Sign In, not profile picker. - Switching user shows Sign In, not profile picker. - Creating an account creates numeric `user_id`. - Creating a flock creates numeric `flock_id` and `member_id` immediately. - Joining a flock creates numeric `member_id` immediately. - Admin login routes to Admin Flock Directory. - Normal users route through `flock_members`. - Join/Create Flock only appears when a signed-in normal user has zero memberships. - No relationship field contains values like `mom`, `dustin`, or Firestore IDs. - Exports show clean numeric ID lanes.
